Analytics

Every event this engine sees is written to disk as it happens — gifts, comments, likes, shares, follows and joins — so a stream can be analysed afterwards. Files are per day, and the CSVs open straight in Excel with Amharic names intact. Nothing here needs the game to be open.

Turn this off while testing and nothing is written to disk — no events, no rollups. The game keeps playing either way.
